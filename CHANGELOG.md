## [0.1.0] - 2026-11-08

### Added

- Affected, related, since-last-run, and last-failed selection for Node's native test runner.
- Static and runtime dependency capture with conservative full-suite fallbacks.
- One-shot and portable two-stage affected-first full-suite gates.
- Workspace routing, watch mode, structured JSON output, onboarding, and diagnostics.
- Node 26 native TypeScript development with JavaScript-only package artifacts.
